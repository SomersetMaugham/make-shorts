## 후보 A. 인디 테크 랩노트 (Pixel-Editorial Labnote)

**한 줄 요약:** 이미 채택한 24×24 픽셀 전구 스팅(`assets/gfx/sting.js`)의 감성을 본문 전체의 시각 언어로 확장한, 경쾌하고 개성 있는 엔지니어링 노트 스타일.

### 어울리는 주제
- AI 모델·도구 실험기, 개발자 팁, 오픈소스 프로젝트 리뷰, 기술 비교/벤치마크 쇼츠
- 진지한 논문 해설보다 약간 더 친근하고 실험실·메이커 감성이 어울리는 콘텐츠

### 시각 토큰 & 조형 방향
| 요소 | 방향 | `sungkim`과의 차별점 |
|---|---|---|
| 배경 | 쿨 오프화이트 `#F4F5F2` + 미세한 24 px 도트 그리드 | 웜 크림 `#F6F3E9` 탈피, 픽셀 스팅의 24×24 격자와 은은하게 호응 |
| 카드 서피스 | 순백 `#FFFFFF`, 작은 모서리(`radius: 8~10px`), 얇은 잉크선(`1.5px solid #1C1E22`) | 사방 2.5px 컬러 둥근 테두리(`radius: 20px`) 제거 |
| 강조 장치 | **좌측 8 px 컬러 액센트 바** + 얕은 하드 오프셋 그림자(`4px 4px 0 rgba(28,30,34,.12)`) | 플랫하고 둥근 카드 대신 촉감 있는 스탬프/카드 인덱스 느낌 |
| 배지 | 각진 인덱스 태그(`radius: 4px`) + `Geist Mono` 번호 (`[01] 복제`, `KEY`, `RISK`) | 둥근 풀-필 배지(`.skb`) 제거 |
| 타이포 | `Pretendard`(본문/제목) + `Geist Mono`(번호·출처·수치 메타) | 올-산세리프 단조로움 해소 |
| 스팅 연동 | 오프닝·엔딩 픽셀 전구 외에, 핵심 인사이트(유레카 순간)·결론 카드 옆에 **미니 픽셀 전구/스파크 점등** 배치, 섹션 전환 시 짧은 픽셀 디바이더 | 오프닝/엔딩과 본문의 시각적 단절 해소 |
| 커버 (Run 0) | 본문과 어울리는 다크 차콜 또는 쿨 그레이 표지, 좌측 정렬 헤드라인, 픽셀 전구를 표지 엠블럼으로 통합, 오렌지 알약 대신 얇은 프레임 팩트 바 | 성킴 특유의 중앙 골드 + 주황 알약 공식 탈피 |

### 구현 시 참고
- `assets/gfx/sting.js`의 24×24 그리드 렌더러를 재사용해 작은 상태 아이콘(전구 점등, 스파크, 체크)으로 확장 가능.
- 상단 프로그레스 바를 픽셀 블록(`■ ■ □ □ □ □`) 형태로 표현하면 세계관 통일감이 매우 높음.

## 후보 C. 다크 라이트박스 브리핑 (Midnight Slate Lightbox)

**한 줄 요약:** 깊은 슬레이트 다크 배경 위에 논문·웹 원문 캡처만 밝은 라이트박스처럼 띄워, 첫 0.1초 만에 `sungkim`(밝은 종이)과 완전히 분리되는 테크 인텔리전스 브리핑 스타일.

### 어울리는 주제
- 보안·리스크 분석, 빅테크 발표 속보, 심층 기술 브리핑, 야간/다크모드 시청자 비중이 높은 테크 쇼츠
- `stage` 테마의 시네마틱 3D/글래스 연출보다 구조화된 정보 전달(헤더+근거+요약 카드)이 더 중요할 때

### 시각 토큰 & 조형 방향
| 요소 | 방향 | `sungkim` / `stage`와의 차별점 |
|---|---|---|
| 배경 | 딥 슬레이트 플랫 `#0F131A` (스포트라이트·빔·글로우 없음) | `sungkim`(밝은 종이)과 즉각 분리, `stage`(그래파이트+블러+빔)와도 결을 달리하는 매트 에디토리얼 다크 |
| 커버 → 본문 전환 | 커버(`#0B0F17`)와 본문(`#0F131A`)의 명도 차이를 최소화 | `sungkim`의 어두운 커버 → 밝은 종이 전환 시 생기는 눈부심(화면 번쩍임) 제거 |
| 상단 카드 (`#skVis`) | 원문 캡처는 **밝은 종이 그대로** 유지 + 은은한 외곽선으로 어두운 데스크 위의 **라이트박스** 효과 | 어두운 배경 속에서 근거 자료에 시선이 강하게 집중됨 |
| 하단 카드 (`#skCards`) | 짙은 슬레이트 카드(`#171C26`), `1px solid rgba(255,255,255,.10)`, 상단 또는 좌측 절제된 컬러 라인 | 네온 글로우 없이 높은 명도 대비의 잉크톤 액센트(에메랄드·앰버·코랄·아이스블루) 사용 |
| 자막 | 화이트 `Pretendard 700` + 다크 슬레이트 아웃라인, 키워드는 현재 섹션의 밝은 액센트 컬러 + 밑줄 스윕 | 밝은 종이용 블랙 자막과 대비되는 고대비 다크 자막 |
| 출처 라인 (`#skSrc`) | `Geist Mono` + 얇은 상태 도트(실제 자료 = 에메랄드, 개념 = 슬레이트 그레이) | 정보 위계가 어두운 화면에서도 또렷함 |

### 구현 시 주의
- 기본 `stage` 테마(`references/theme.md`)도 다크 톤이므로, 글래스 블러(`backdrop-filter`), 네온 블룸, 카메라 줌을 일절 쓰지 않고 **플랫·매트·구조적 정보 카드**로 선을 그어야 정체성이 겹치지 않는다.
- 밝은 원문 캡처가 화면 전체 대비를 지배하므로, 캡처 외곽에 미세한 내부 테두리(`inset 0 0 0 1px rgba(0,0,0,.08)`)와 적절한 패딩을 유지한다.

## 공통 확장 아이디어 (후보 A·C 및 채택안 B 공통 적용 가능)
어느 후보를 추후 구현하더라도 4단 뼈대 위에 아래 기능은 공통 자산으로 재사용할 수 있다.
1. **섹션 프로그레스 바 + 챕터 번호 (`02 / 06`)**: 헤더 상단 고정 내비게이션.
2. **섹션 연동 자막 키워드 색상**: `compose.py` / `preview.py`에서 하드코딩된 단일 색 대신 현재 런의 섹션 색상을 따라감.
3. **근거 등급 미니 칩 (`SOURCE_KINDS`)**: `실제 자료`·`실제 그림`·`계산해서 그린 그림`·`개념 그림`을 시각적 등급으로 구분.
4. **캡처 강조 옵션 확장 (`capture_html`)**: 빨간 밑줄 외에 형광펜 마커 워시(`multiply`) 및 포커스 외 영역 스포트라이트 딤 옵션.
5. **카드 모션 변주 & 비율 프리셋**: 숫자 카운트업(`number_card`), 키워드 하이라이트 스윕, 상/하 카드 높이 프리셋(`default` / `visual_tall` / `cards_tall`).
