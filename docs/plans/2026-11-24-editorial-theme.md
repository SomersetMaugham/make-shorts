## 1. 계승할 뼈대 vs. 바꿀 정체성

### 유지하는 뼈대 (구조적 강점)
- **9:16 안전영역 & 4단 정보 계층**:
  - 헤더(`y 64–308`) → 상단 근거 비주얼(`#edVis`) → 출처 바(`#edSrc`) → 하단 압축 카드(`#edCards`, `y <= 1384`) → 자막(`1410–1550`) → 하단 빈 영역(`1560–1920`), 우측 버튼 칼럼(`x > 960`) 텍스트 회피.
- **섹션 리듬**: 5~8개 섹션, 각 섹션 2~5런 동안 헤더 유지, 하단 카드는 소주제 전환 시 비우고 새로 쌓음(`LEAD = 0.3s`).
- **근거 중심 원칙**: `capture_marks.py` 기반 가독성 검증(`MIN_CAPTURE_TEXT = 26px`, `keep` 보호)과 4종 출처 분류(`실제 자료`, `실제 그림`, `계산해서 그린 그림`, `개념 그림`).

### 탈피하는 지문 (`sungkim`과의 명확한 시각적 분리)
| 영역 | `sungkim` (기존) | 신규 매거진 테마 (방향 B) |
|---|---|---|
| 배경 | 웜 크림 `#F6F3E9` | 차분한 **뉴스프린트/스톤 `#F5F4F0`** + 극미세 지면 그레인(선택) |
| 구분선 | 없음 (둥근 박스 나열) | **에디토리얼 룰(Editorial Rule)**: 굵은 잉크선 `2px #18181B` + 얇은 헤어라인 `1px rgba(24,24,27,.16)` |
| 타이포그래피 | `Pretendard` 단일 (600–900) | **3단 대비**: 명조(한글 세리프: 헤드라인·인용·핵심 문장) + `Pretendard`(본문·카드·자막) + `Geist Mono`(섹션 번호·출처·데이터 수치) |
| 컬러 시스템 | 틸·블루·골드·레드·퍼플 (성킴 6색) | **잉크 중심 + 절제된 매거진 액센트** (딥 버건디/크림슨, 옥스퍼드 네이비, 포레스트 그린, 앤티크 오커, 슬레이트) |
| 카드 문법 | `radius: 20px`, 사방 2.5px 컬러 테두리 + 풀-필 배지(`.skb`) | **각진 에디토리얼 시트(`radius: 4~6px`)**, 상단 4px 컬러 룰(top rule) 또는 좌측 세로선 + 얇은 외곽선 + 타이포그래픽 소제목 라벨 |
| 커버 (Run 0) | `#020611` 암전 + 중앙 골드 마지막 줄 + 오렌지 알약 | **매거진 표지 레이아웃**: 상단 이슈/카테고리 바 + 좌측 정렬 대형 세리프 헤드라인 + 구분선 + 하단 팩트 스트립(오렌지 알약 제거) |
| 헤더 내비게이션 | 키커 + 제목만 | 상단 **얇은 섹션 프로그레스 바 + `02 / 06` 모노 인덱스** |

## 2. 세부 비주얼 & 모션 설계안

### 2.1 팔레트 제안 (잉크 우선, 저채도 고급 톤)
- **지면(Surface)**:
  - Paper `#F5F4F0` / Card Sheet `#FCFBF8` / Ink `#161618` / Ink-2 `#4A4A52` / Muted `#76767F` / Rule `#D8D6CE`
- **섹션 액센트 (`PALETTE`)**:
  - `crimson` (기본/강조/핵심 이슈 — 이코노미스트·타임 계열): `#9B1C1C` / `#B91C1C`
  - `navy` (설명/구조/배경): `#1B3B6F` / `#284E8C`
  - `forest` (검증/성공/해법): `#1B5E4A` / `#257860`
  - `ochre` (수치/전환/비교): `#9A6314` / `#B87A1E`
  - `plum` (의미/전망/확장): `#5B3A6B` / `#734B87`
  - `slate` (질문/중립): `#47505C` / `#647080`
- *포인트*: 모든 제목을 채도 높은 색으로 칠하기보다, **제목은 진한 잉크 `#161618`을 기본으로 두고 키커·상단 룰·핵심 숫자·인용 따옴표·섹션 바에만 섹션 색을 써서** 인쇄 잡지 특유의 품격을 살리는 옵션도 강력 추천(또는 제목만 섹션 다크 톤).

### 2.2 타이포그래피 페어링
- **한글 세리프(명조) 1종 추가** (`setup.sh`의 `fetch` + sha256 검증 방식 그대로 SIL OFL 폰트 도입):
  - 후보 1: **Noto Serif KR** (Bold 700 / ExtraBold 800, 정통 신문·학술지 감성, 글리프 커버리지 최상)
  - 후보 2: **Hahmlet** (Google Fonts OFL 가변 폰트, 현대적이고 단단한 에디토리얼 명조, 모바일 9:16 가독성 우수)
  - 후보 3: **Gowun Batang** (Google Fonts OFL, 부드러운 잡지·에세이 톤)
- **역할 분담**:
  - **명조**: 커버 메인 타이틀, 섹션 타이틀(`#edTitle`), 인용 카드(`quote_card`), 결론 문장(`statement_card`)
  - **Pretendard**: 카드 본문, 비교 막대 라벨, 자막(모바일 가독성 최우선)
  - **Geist Mono**: 섹션 번호(`02 / 06`), 출처 태그(`SOURCE`), 큰 수치 강조 보조, 타임스탬프/버전

### 2.3 헤더 & 프로그레스 내비게이션 (`y 60–310`)
- 최상단(`y 60`): 얇은 **세그먼트 프로그레스 바** (총 섹션 수만큼 분할, 지나온/현재 섹션만 채움) + 우측 `02 / 06` (`Geist Mono 28px`, `x <= 960` 준수).
- 바로 아래(`y 96`): 키커(섹션 컬러, 대문자/짧은 한글 라벨) + 1줄 대형 명조 타이틀(`#edTitle`, 자동 축소 `104px → 70px`).
- 하단 마감: **2px 잉크 실선**으로 본문과 명확히 구획.

### 2.4 상단 근거 카드 (`#edVis`) & 출처 아카이브 바 (`#edSrc`)
- 상단 카드: 과한 그림자와 큰 라운드(`radius: 20px`) 대신 **샤프한 프레임(`radius: 6px`, `1.5px solid #161618` 또는 연한 잉크 보더)**으로 인쇄 지면 위의 도판(Figure)처럼 보이게 구성.
- 출처 바: 카드 바로 아래에 붙는 **아카이브 캡션 스트립**.
  - `실제 자료` / `실제 그림`: 솔리드 컬러 도트 + `[실제 자료]` 칩
  - `계산해서 그린 그림`: 아웃라인 칩
  - `개념 그림`: 점선/슬레이트 칩 (사실과 개념을 시각적으로 즉시 구분)
- `capture_html` 확장:
  - 기존 빨간 밑줄(`mark_style='underline'`) 외에 **에디토리얼 형광펜 마커(`mark_style='highlight'`, `multiply` 워시)** 및 **비초점 영역 은은한 딤(`dim=True`)** 옵션 추가.

### 2.5 하단 카드 문법 & 비율 프리셋
- 기존 8종 빌더(`badge_card`, `statement_card`, `quote_card`, `number_card`, `bars_card`, `pair_card`, `units_card`, `tiles_card`)의 **Python 호출 인터페이스는 최대한 호환**되게 유지해 대본→그래픽 작성 생산성을 그대로 가져간다.
- 조형 변경:
  - `badge_card`: 둥근 알약 대신 **좌측 4px 컬러 룰 + 작은 모노/대문자 태그 + Pretendard 700 요약줄** (구분선 기반 인쇄 리스트 감각).
  - `quote_card`: 좌측 굵은 컬러 바 + 대형 명조 여는 따옴표(`“`) + 명조 인용문 + 하단 출처/해석.
  - `number_card`: 상단 얇은 컬러 룰 + 거대한 수치(카운트업/롤링 애니메이션 지원) + 짧은 해석줄.
  - `statement_card`: 상·하 잉크 룰이 감싸는 **에디토리얼 풀-쿼트(Pull-quote) 박스**.
- **비율 프리셋 (`layout` 인자)**:
  - `'default'`: 상단 550 px / 하단 400 px
  - `'visual_tall'`: 상단 660 px / 하단 280 px (복잡한 논문 도표·차트 강조)
  - `'cards_tall'`: 상단 430 px / 하단 510 px (2×2 타일·비교 막대·결론 카드 강조)

### 2.6 모션 & 자막 연동
- **카드 등장**: 단순 `translateY(16px)` 일괄 적용에서 벗어나, 카드 성격별 절제된 모션 부여:
  - `number_card`: 숫자 카운트업(옵션 `count_from` / 자동 파싱)
  - `quote_card` / `statement_card`: 상단/좌측 룰이 먼저 그려진 뒤(`scaleX`/`scaleY`) 텍스트가 또렷이 등장
  - `bars_card` / `units_card` / `tiles_card`: 기존 순차 채움 유지 + 이징 다듬기
- **자막(`compose.py` / `preview.py`)**:
  - 기본 자막: `Pretendard 700 50px` 잉크 블랙 + 지면 색(`#F5F4F0`) 아웃라인.
  - 키워드 강조: 기존 `sungkim`처럼 틸 고정하지 않고, **각 런의 섹션 색상(또는 프로젝트 지정 기본 액센트)**으로 동적 적용.

## 3. 구현 시 예상 파일 영향 범위 (참고)

기존 `sungkim` 관련 파일은 건드리지 않고, 아래처럼 독립적으로 추가·연결한다.
- 신규 추가:
  - `references/theme-<name>.md` (테마 명세서)
  - `scripts/<name>_kit.py` (파이썬 빌더 키트)
  - `assets/gfx/<name>.js` (프레임 렌더 런타임)
  - `assets/fonts/<SerifFont>.ttf` + OFL 라이선스 (`scripts/setup.sh`에 sha256 검증 다운로드 추가)
- 분기 연결 (기존 테마 영향 없음):
  - `scripts/config.py`, `scripts/init_project.py` (테마 목록 주석/설정)
  - `scripts/compose.py`, `scripts/preview.py` (새 테마 자막·키워드·커버 분기 + 섹션별 강조색 연동)
  - `scripts/defect_check.py` (새 테마 설명·레퍼런스 경로 등록)
  - `SKILL.md`, `references/theme.md` (새 테마 트리거 문구 및 안내 추가)
